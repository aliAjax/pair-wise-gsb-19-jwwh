# hxwl-05 多鱼缸水质追踪台

多鱼缸水质检测、异常处置闭环、换水回填与版本化修正，数据本地落盘。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能

- **多鱼缸管理**：每个鱼缸独立记录检测时间、pH、氨氮、硝酸盐、温度与换水量
- **异常强制处置**：pH <6 或 >8.5、氨氮 >0.2mg/L、硝酸盐 >40mg/L、温度 <22℃ 或 >30℃ 时，必须逐项登记处置动作才能保存
- **换水门禁**：异常未关闭时禁止记录换水完成（可登记计划）
- **回填估算**：换水完成按换水量比例回填估算浓度（氨氮/硝酸盐按比例稀释，pH 向 7.0、温度向 25℃ 回归），生成独立的估算记录
- **不可覆盖**：记录保存后不可修改，修正只能新建带原因的版本，历史版本链完整保留
- **持久化**：localStorage 自动落盘，支持导出 / 导入 JSON 文件
- **一致性检查**：刷新或导入后自动校验鱼缸、检测、处置与换水链，冲突按「鱼缸 / 指标 / 原值 / 新值 / 触发规则」列出：
  - 修正后处置依据失效
  - 回填基准被修正导致估算需重算
  - 异常未登记处置
  - 异常未关闭时完成换水
  - 孤儿记录（链断裂）

## 目录

- `src/domain.ts` — 数据模型、异常规则、回填模型、冲突检测
- `src/store.ts` — localStorage 持久化与导入校验
- `src/App.tsx` — 看板界面与交互
