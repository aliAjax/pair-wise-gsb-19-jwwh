# hxwl-05 多鱼缸水质追踪台

多鱼缸水质检测、异常处置、换水回填与版本化修正的本地落盘看板。

## 技术栈

React + Vite + TypeScript + CSS，数据持久化在浏览器 localStorage（刷新不丢，可导出 JSON）。

## 本地运行

```bash
npm install
npm run dev          # 开发端口 5105
npm run test:logic   # 运行业务规则断言（阈值/回填/冲突/链校验）
npm run build
```

## 业务规则

- **检测登记**：每个鱼缸记录检测时间、pH、氨氮、硝酸盐、温度和本次换水量（%）。
- **异常阈值**：pH < 6 或 > 8.5；氨氮 > 0.2 mg/L；硝酸盐 > 40 mg/L；温度 < 22℃ 或 > 30℃。
- **处置前置**：检测触发任一阈值时，必须逐项登记处置动作，否则禁止保存。
- **换水闭锁**：鱼缸存在未关闭的异常处置时，禁止记录换水完成（按钮禁用并提示）。
- **回填估算**：换水完成按换水量比例回填估算浓度——氨氮/硝酸盐按 `(1 - 比例)` 稀释，pH 按比例向中性 7.0 回归，温度保持不变；估算值作为当前读数直到下一次实测。
- **不可覆盖**：检测记录保存后不可修改；修正只能基于最新版本新建带原因的新版本（v2、v3…），原版本保留可查。
- **冲突留痕**：修正版本与换水回填估算 vs 实测偏差（>10%）会列出鱼缸、指标、原值、新值和触发规则。
- **链一致性**：每次渲染对 鱼缸—检测—处置—换水 引用链做校验，刷新后状态一致；断链会列入冲突面板。

## 文件结构

- `src/water.ts` — 领域模型与纯逻辑（阈值、回填、冲突、链校验）
- `src/storage.ts` — localStorage 落盘与示例数据
- `src/App.tsx` — 看板界面与交互规则
- `src/logic.test.ts` — 业务规则断言（`npm run test:logic`）
